## Canonical vertical slice

`commit0:cachetools` currently demonstrates:

```text
task materialization
-> natural subproblem assignment
-> model-specific agent execution
-> complete file edits
-> generated patch
-> integrated workspace
-> pytest
-> saved run and failure analysis
```

The numerical dry-run results are exploratory. They validate the data path but
do not yet establish a strong single-agent baseline or true asynchronous
execution.

The cachetools data quality status is `qualification_ready`. Its quality
record explicitly notes that decorator-factory tests require an integrated key
artifact; this dependency must not be mislabeled as freshness harm.

AsynCodeBench no longer has a runtime or documentation-path dependency on
the predecessor workspace. Commit0 runners default to project-local
repositories and accept an explicit `--repo` override.

`commit0:deprecated` is the second generated candidate. Its natural split is
Classic warning/decorator behavior versus the dependent Sphinx
directive/adapter layer. It has not yet been run through the shared iterative
agent implementation. Its data quality status is `qualification_ready`;
human annotation remains pending. Single-agent, serial-specialist, and async
results are evaluation outputs to be reported later.

`commit0:portalocker` is a qualification-ready POSIX core task with a natural
backend → utilities interface dependency. A two-function empty bootstrap
restores package import without supplying locking semantics. The curated state
collects 40 tests with 8 passed and 32 failed; completed v2.10.1 passes all 40.
RedisLock is excluded because it requires a separate package and running
service. Annotation remains pending; baseline and async results are evaluation
outputs to be reported later.

`commit0:tinydb` has both interface-dependency and shared-abstraction
structure. A versioned two-edit overlay restores only the runtime
class-definition prerequisites, without implementing correct FrozenDict,
query, storage, table, database, or middleware behavior. The curated initial
state collects all 201 tests with 5 passed, 71 failed, and 125 errors. The
completed public v4.8.0 tag passes all 201 tests. Its data quality status is
`qualification_ready`; annotation remains pending. Single-agent,
serial-specialist, and async results are evaluation outputs to be reported
later.

`commit0:wcwidth` is a compact interface-dependency task. It keeps raw Commit0
unchanged and uses a core evaluator that excludes one package-metadata test so
the benchmark measures implementation behavior rather than editable-install
state. The initial core evaluator has 37 failures and one upstream skip; the
completed public branch passes the same 37 active tests. Its split is
Unicode-version catalog specialist into terminal-width algorithm specialist.
Annotation remains pending; baseline and async results are evaluation outputs
to be reported later.

## Human qualification gate

The cachetools and Deprecated TaskRecords remain:

```text
qualification_status = pending_independent_annotation
official_result_eligible = false
```

The proposed `partially_parallelizable` label is demonstrative only. Two
different humans must complete the annotation forms. The finalization script
rejects blank, duplicate, or unadjudicated disagreement records.
