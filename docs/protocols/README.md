# Protocols

Operational and preregistered protocols for qualification, anti-leakage,
replay/live validation, statistics, and release maintenance belong here.

- `QUALIFICATION_PROTOCOL_v0.2.md`: frozen task qualification protocol.
- `ANNOTATOR_GUIDANCE_v0.3.md`: field-level instructions for completing
  independent v0.3 annotation templates and adjudication forms.
- `COMMIT0_DATA_EXAMPLE_GUIDE_v0.3.md`: consistency guide and worked
  `commit0:cachetools` example for turning a Commit0 candidate into an
  AsynCodeBench data example.
- `COMMIT0_DEPRECATED_DATA_EXAMPLE_v0.3.md`: second worked example covering
  the Classic-to-Sphinx dependency and its asynchronous freshness risk.
- `COMMIT0_PORTALOCKER_DATA_EXAMPLE_v0.3.md`: qualification-ready POSIX core
  example with a checksum-pinned bootstrap and two-specialist split.
- `COMMIT0_TINYDB_DATA_EXAMPLE_v0.3.md`: third qualification-ready example;
  records the checksum-pinned curated bootstrap, two-specialist split, and
  evaluator evidence.
- `COMMIT0_WCWIDTH_DATA_EXAMPLE_v0.3.md`: compact qualification-ready
  interface-dependency example covering Unicode version catalog handoff into
  terminal-width behavior.
