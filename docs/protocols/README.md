# Protocols

Operational and preregistered protocols for qualification, anti-leakage,
replay/live validation, statistics, and release maintenance belong here.

- `QUALIFICATION_PROTOCOL_v0.2.md`: frozen task qualification protocol.
- `ANNOTATOR_GUIDANCE_v0.3.md`: field-level instructions for completing
  independent v0.3 annotation templates and adjudication forms.
- `COMMIT0_DATA_EXAMPLE_GUIDE_v0.3.md`: consistency guide and worked
  `commit0:cachetools` example for turning a Commit0 candidate into an
  AsynCodeBench data example.
